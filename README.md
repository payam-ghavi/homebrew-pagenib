# Pagenib for Homebrew

[Pagenib](https://pagenib.com) is a PDF viewer and editor for construction drawings: measure at scale, mark up,
fill in and sign PDFs. This tap installs the Mac app (Apple silicon, macOS 12 or later), signed and notarized by Apple.

```
brew install payam-ghavi/pagenib/pagenib
```

Pagenib updates itself; `brew upgrade --cask pagenib` works too. Windows and Linux: see https://pagenib.com.
